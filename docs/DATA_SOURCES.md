# Data distribution policy and source references

## Publication decision

This repository publishes software, documentation, synthetic regression fixtures and illustrative screenshots of the interfaces. Official classification workbooks and generated JSON datasets are not distributed. A hosted classification-data API is outside the project's publication scope. No additional dataset redistribution-permission process is planned.

Source files and generated datasets remain local and ignored by Git. Import instructions are technical references for users who independently hold material they may lawfully use; they supply no files, automatic download or additional third-party data rights.

## Interface screenshots

The README screenshots show the actual ICD-10-IM and CIPI interfaces with selected classification codes and descriptions. They are illustrative excerpts, contain no patient records and are not a downloadable classification dataset. Source attribution is provided beside each image and below. Classification text remains under the source license, not the project's MIT license. The interface displays the original labels without translating or rewriting them for these previews.

The screenshots form part of the academic project's documentation and are not presented as an official service or as source-owner endorsement. They do not establish redistribution permission for full datasets or transformed databases. Regression tests separately use synthetic fixtures and need no official data.

## Source references retained for context

The following records describe the notices observed in the author's local workbooks on 2026-10-27. They do not indicate that files are supplied, that the references identify the latest release or that additional redistribution rights have been obtained.

The local gamma 2.1 workbook (December 2025, ICD-9-CM crosswalk, excluding chapter XX) names Ministero della Salute and Regione Autonoma Friuli Venezia Giulia and specifies CC BY-NC-ND 4.0. Its requested citation is:

> Ministero della Salute e Regione Autonoma Friuli Venezia Giulia, Elenco sistematico ICD-10-IM, versione gamma, 2.1 - Dicembre 2025, con transcodifica in ICD-9-CM (senza capitolo XX). Licenza: CC BY-NC-ND 4.0

Reference: [Ministry ICD-10-IM page](https://www.salute.gov.it/new/it/tema/assistenza-ospedaliera-sdo/la-classificazione-delle-diagnosi-icd-10-im/).
